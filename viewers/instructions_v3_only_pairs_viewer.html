Instruction-following — the red-team pairs that are new at iteration 3

Only the pairs in the iteration-3 training set that are not in the iteration-2 vintage: rows held out of every v2 probe fit, on both sides of the split. 240 pairs across both attackers.
v2 hits is how many of the 10 independently seeded v2 probes misclassify that conversation — i.e. how many of them the find still beats. 10/10 is a robust probe weakness; 0/10 is a find that only beat the one probe draw the run happened to be handed. Thresholded at logit ≥ 0, as ProbeJudge does.
Left column is the attacker's submission (the judge disagreed with the probe on it); right column is the LLM-written opposite-class counterpart preprocessing generated from it. Both were trained on at iteration 3.
“New at iteration 3” is about the training set, not about when the attacker found it — filter_dataset drops a different top-percentile each cycle, so some of these were found in an earlier rotation, dropped from the iteration-2 set and taken back later. The found in iteration chip shows which rotation each one came from.
