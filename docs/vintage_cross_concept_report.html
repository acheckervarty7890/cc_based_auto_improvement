The question

The vintage sweep shows that adding iteration-2 and -3 red-team pairs keeps raising high-stakes AUROC — 0.868 at v0 to 0.933 at v3 on the gpt-oss arm. What that curve cannot say is what the probe learned. A conversation written to trip a high-stakes probe also has unusual register, length and topic, and a fit that improves on the high-stakes splits might be picking up any of it.

If the red-team data taught the probe high-stakes, its effect should stay inside high-stakes. If it taught something generic about attacker-written text, it should lift other concepts' eval sets too. So the same probes were scored on two eval sets they were never trained for.

What makes this comparable

Nothing was refitted. The checkpoints in vintage/fits/ are the probes behind the sweep's own summary, reloaded through the same path its resume uses. That identity is verified, not asserted: re-scoring the high-stakes splits through this script's separately-written loading and scoring code reproduces the published vintage_auroc.csv to max |diff| = 0.0 over 32 fit × split cells.

The activations are interchangeable. Every blob — all three concepts — is gemma-3-27b-it layer 32 under the same two loader transforms. An activation is a property of the conversation and the frozen extraction model, not of the probe head that reads it. Only the labels differ, and those come from the split.

AUROC is measured against each split's own positive class and left unflipped. 0.50 means the high-stakes score carries no information about the other concept; below 0.50 is a genuine anti-correlation, and flipping it would hide the sign. An off-concept AUROC is not a quality score — the probe was never asked to do that job. It is comparable only across vintages, which is the point: v0 fixes the entanglement the base data already carries, and v1–v3 show which way red-team data moves it.

Four readings

01

The gains do not transfer

Every off-concept cell sits within about 0.09 of chance at every vintage, while the same fits climb 6.5 points on high-stakes. Whatever the red-team pairs teach is concept-specific — not a generic "attacker-written text" signal, which would have lifted the foreign eval sets too.

02

The one large cross-concept signal is inherited, not manufactured

eval_ant_hh is a real outlier: the high-stakes score ranks harmful-to-human above not-harmful at roughly 0.84. But it is already 0.8387 ± 0.0161 at v0, the fit with zero red-team rows, and stays in 0.806–0.851 across every vintage of both arms. That entanglement comes from the base training set. Red-teaming neither created nor meaningfully moved it, and the other three human-harm splits stay at chance throughout.

03

The only real movement is at v1, and it decays

Both arms perturb off-concept at vintage 1 and drift back by vintage 3 — in opposite directions on the two eval sets. On instructions, deepseekv4pro goes 0.4672 → 0.5519 (+0.0847, 2.2σ against the pooled seed sd), almost entirely from bbq_substitution reaching 0.7557 ± 0.0156; by v3 that split is back to 0.5010. On human-harm the same arm drops 0.5864 → 0.5233 (−0.0631, 5.1σ) as eval_daily_dilemmas falls to 0.3763, recovering to 0.4981 by v3. gptoss120b shows the same shape, smaller.

The iteration-1 set is the smallest and least diverse — 228–294 rows against 562–716 at v3 — so the natural reading is that a narrow early set pulls the boundary somewhere idiosyncratic and later, broader vintages average it out. The data supports that; it does not establish it.

04

Neither conclusion depends on the AUROC scale

The pipeline scale scores saturated bf16 probabilities, so rows above logit ≈ 5.5 tie at 1.0; the rank scale scores fp32 logits. They agree to within 0.001 on every off-concept cell except human-harm v0 (0.5864 vs 0.5955). Sub-chance cells are real and reported as such — mm_substitution bottoms out at 0.3245 ± 0.0212, meaning the high-stakes score ranks instruction-following responses below violating ones there.

A second sweep: each iteration's increment, fitted alone

The curve above is cumulative — v3 contains v2 contains v1 — so a later vintage is both newer data and more data. That leaves its plateau ambiguous: either iteration 3's finds are individually weaker, or they are redundant with what the set already holds. A second sweep separates the two by fitting each increment on its own: v1, then v2-minus-v1, then v3-minus-v2, everything else held fixed. 40 more fits.

v1 is the same set under both memberships — nothing earlier to subtract — so its fits are reused rather than recomputed. That reuse is visible in the chart below as an exactly zero gap on every v1 row.

05

On its own concept, it's redundancy — not decay

Every increment alone is statistically indistinguishable from the whole cumulative set containing it. gptoss120b's 140-row v3-only slice scores 0.9321 where the 562-row v3 scores 0.9326 — 0.1σ. About three quarters of the final training set can be dropped without a measurable cost.

Per row the later data is the better data, which is the opposite of what the plateau suggests: v3-only beats v1 by 3.2σ on gptoss120b using 140 rows against 228, and v2-only beats v1 on both arms. So the deepseekv4pro dip at cumulative v3 is a property of the mixture, not of iteration 3's conversations.

06

Off-concept, isolating the increments changes nothing — except at v2

Every slice fitted alone still lands near chance on both foreign eval sets, so the no-transfer conclusion survives the decomposition. v3-only matches cumulative v3 everywhere (0.1–1.9σ). But v2-only differs from cumulative v2 in all four arm × concept cells, and consistently: iteration 2's new conversations alone push the probe further from chance in both directions — up on human-harm (+0.038 / +0.017, 2.4σ / 2.3σ), down on instructions (−0.034 / −0.048, 3.7σ / 4.0σ). Mixing v1 back in pulls it toward the middle, so the cumulative set's off-concept behaviour is partly two increments cancelling.

That masking hides the sharpest single result in the whole analysis: gptoss120b's v2-only slice drives anthropic_harmless_refusal to 0.2766 ± 0.0414 — a strong anti-correlation, invisible in the cumulative table.

What this does not show

  • v0 is identical across arms by construction — 0.5864 and 0.4672 are not a copy-paste. v0 holds no red-team rows, so the arms only diverge from v1 on.
  • The vintages are not strictly nested. A vintage is "every iteration-3 pair whose originating success already existed at iteration N", carrying iteration 3's content, because the filter refits per cycle and drops a different top percentile each time. That is faithful to what the runs trained on, not an idealised add-only curve.
  • Ten seeds, unpaired. The sd columns are the yardstick; a between-vintage gap inside the seed noise is not evidence. Only gaps of ≥2σ are called out.
  • This measures these probes, not the concepts. That high-stakes and human-harm are entangled on eval_ant_hh is a fact about these fits and that split, not a claim the two concepts coincide in general.
  • The increments differ in size as well as in vintage. "Later data is better per row" is therefore confounded with "smaller training sets behave differently here". A size-matched subsample of v1 would settle it; that run has not been done.
